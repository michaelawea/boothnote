# 客户术语、AI 建客与国家字段（#60–#62）

中文和英文界面都显示 `distributor` / `dealer`（含 `sub-distributor` / `sub-dealer`），存储枚举值不变。
点击 AI 提议会打开新建表单，预填名称及原文明确的国家/类型；未说明或不合法的值留空。
用户可修改，保存仍走强制查重；选用已有客户或创建成功后自动选中，并在残留搜索词下保持可见。

## 国家字段升级

国家选项由 `shared/countries.mjs` 统一提供，保存 ISO 3166-1 alpha-2 代码。
PWA 使用必选下拉，网关在任何 CRM 请求前验证；直接在 CRM 编辑时由 SELECT 限定选项。

现有 `company.hqCountry` 是 TEXT，不能通过字段更新接口直接改成 SELECT。因此新增 `hqCountryCode` SELECT，
保留旧文本列及数据；读档案/情报完整度/门户的 `hqCountry` 返回契约映射到新代码。
新字段明确清空时不会从旧文本恢复；仅字段尚不存在的旧 schema 使用旧文本兼容读取。

部署前按现有流程保存标签备份与数据快照。先在目标 Twenty 上同步元数据，再预览：

```bash
node scripts/provision-twenty.mjs
node scripts/migrate-company-countries.mjs
```

预览只读，列出将回填的数量和无法识别的历史值。已选择的代码不会被历史文本覆盖。
确认目标环境及预览清单后执行：

```bash
node scripts/migrate-company-countries.mjs --apply
```

脚本验证新字段为完整、启用的 SELECT，读完全部分页，回填能明确识别的国家并逐条回读。
全部回填成功后才通过 Metadata API 停用旧 TEXT 输入；不会删字段、删记录或修改旧文本。
遇到缺失分页信息、循环游标、非法 SELECT 配置、API 失败或回填未落住时立即停止。
回填可重跑，已经有受控国家的记录不再写。

无法识别的旧值保留在历史字段，新下拉留空；按照脚本输出的客户 id，在 CRM 手动选择正确国家。
执行期间暂停客户国家编辑，避免和回填同时修改同一客户。

`scripts/deploy-server.sh` 已接入迁移，顺序是：备份/快照 → 数据库迁移 → provision → 第一轮数据守卫 →
暂停旧网关 → 国家回填/旧输入停用 → 新网关/PWA → 导入补空/视图更新 → 最终校验。
暂停网关避免迁移读取后仍有请求往旧国家列写入；此时 PWA 本地速记仍可保存。
`--provision-only` 只同步元数据，不回填或停用旧输入。完整部署会完成升级。
国家迁移失败时网关保持停止，修正后重跑完整部署；历史文本仍用于追溯。

回退应用版本时，旧版本只会写旧 TEXT 列；应先在 Metadata API 恢复其 `isActive`，保留新 SELECT 列及已迁移数据。
回退期间新增/修改的国家需要在重新升级时核对，不能假定两列自动双向同步。
