## 1. 通信端口

- 测试连接器：4 Pin 防水圆形连接器 `TEST-M12-A4`；
- 端口标识：`CI-BUS`；
- 总线类型：CI-Bus，测试中使用 CAN 物理层；
- 节点角色：电池为从机节点；
- 标称波特率：500 kbit/s；
- 建议线缆：一对双绞 CAN 信号线，并带独立信号地与屏蔽层。

## 2. Pin 定义

| Pin | 信号 | 方向 | 测试定义 | 备注 |
|---|---|---|---|---|
| 1 | CAN-H | 双向 | CAN 高电平信号 | 与 CAN-L 使用双绞线 |
| 2 | CAN-L | 双向 | CAN 低电平信号 | 与 CAN-H 使用双绞线 |
| 3 | Signal GND | 参考 | 通信参考地 | 不作为主功率负极 |
| 4 | Shield | 屏蔽 | 线缆屏蔽连接 | 测试方案为设备侧单端连接 |

## 3. 测试电气特性

| 项目 | 测试值 |
|---|---|
| CAN 收发器供电域 | 内部隔离 5V |
| 共模工作范围 | -2V～+7V |
| CAN-H/CAN-L 对 Signal GND 最大测试电压 | -3V～+16V |
| ESD 目标 | 接触放电 ±4kV，空气放电 ±8kV |
| 内置终端电阻 | 默认不安装 |
| 总线终端 | 总线两端各 120Ω；断电后 CAN-H 与 CAN-L 间参考测量约 60Ω |

## 4. 接线与检查步骤

1. 全部设备断电后完成 CAN-H、CAN-L、Signal GND 和屏蔽层接线；
2. 检查 CAN-H 与 CAN-L 未反接，Signal GND 未接到主功率正极；
3. 测量 CAN-H 与 CAN-L 间等效电阻，确认终端配置；
4. 先给测试接口上电，再给电池主回路上电；
5. 使用 500 kbit/s、11-bit 标准帧监听总线；
6. 若无报文，依次检查供电、接线、波特率、节点唤醒状态和固件版本。
