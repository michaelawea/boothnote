## 1. 项目背景

Havel 计划在 2027 MY 部分房车平台导入 12V 150Ah LiFePO4 电池。电池需要通过 CI-Bus 与车辆能源管理控制器通信，并满足样品测试、整车验证和量产交付要求。

## 2. 供货范围

- 测试产品型号：`VLB12150-CIBUS`；
- 样品阶段数量：20 台；
- 首年预测数量：14,000 台；
- 量产包装：单台独立包装，可追溯序列号与生产批次；
- 随样资料：数据表、通信说明、Pin 脚定义、安装说明和测试报告。

## 3. 电气参数

| 参数 | 要求 | 备注 |
|---|---|---|
| 电芯体系 | LiFePO4 | 方形电芯 |
| 标称电压 | 12.8V | 4S 系统 |
| 标称容量 | 150Ah | 25°C，0.5C 条件 |
| 标称能量 | 1.92kWh | 参考值 |
| 充电截止电压 | 14.6V | 允许误差 ±0.1V |
| 推荐充电电流 | ≤75A | 0.5C |
| 持续放电电流 | 150A | 环境温度 25°C |
| 峰值放电电流 | 300A，10 秒 | 每次触发间隔不少于 60 秒 |
| 低压保护 | 10.0V | 触发值待样品验证 |

## 4. 通信要求

| 参数 | 要求 |
|---|---|
| 总线 | CI-Bus，基于 CAN 物理层 |
| 节点角色 | 电池作为从机节点 |
| 波特率 | 500 kbit/s |
| 报文周期 | 100ms 或 1s，按信号类型区分 |
| 必需信号 | SOC、SOH、电压、电流、最高/最低温度、充放电允许状态、告警状态 |
| 报文 ID | 由双方在 DBC/协议表中最终确认 |
| 字节序 | Intel little-endian，待协议评审确认 |
| 故障处理 | 通信丢失 3 秒后上报通信超时状态 |

## 5. 机械与接口要求

| 参数 | 要求 |
|---|---|
| 最大外形尺寸 | 485 × 240 × 245mm |
| 最大重量 | 18.5kg |
| 防护等级 | IP65 |
| 主功率端子 | M8 螺柱 |
| 通信连接器 | 4 Pin 防水连接器，具体型号待双方确认 |
| 安装方向 | 允许水平安装；其他方向需书面确认 |

## 6. 环境与合规要求

- 充电温度：0°C～45°C；
- 放电温度：-20°C～55°C；
- 存储温度：-20°C～45°C；
- 振动：按 UN 38.3 T.3 完成验证；
- 运输：满足 UN 38.3；
- 电池安全：提供 IEC 62619 测试计划或证书状态；
- 材料合规：RoHS、REACH 声明。

## 7. 样品验收标准

1. 20 台样品的外观、序列号和包装信息完整；
2. 额定容量实测不低于 150Ah；
3. 持续 150A 放电 30 分钟无保护误触发；
4. 峰值 300A 持续 10 秒测试通过；
5. CI-Bus 上能够稳定读取 SOC、总压、总流和告警状态；
6. 连续运行 72 小时无通信中断或不可恢复故障；
7. 所有测试结果形成可追溯报告。
