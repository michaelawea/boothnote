# Batteries (fictional demo data)

## VLB12100LFP-BT-G1 — Standard, Bluetooth

- Nominal voltage: 12.8V · Capacity: 100Ah · Energy: 1280Wh
- Continuous discharge: 100A · Peak: 200A (10s)
- BMS: over-charge, over-discharge, over-current, short-circuit, low-temperature charge cut-off
- Bluetooth app monitoring
- Operating temperature (discharge): −20 to 60°C · (charge): 0 to 50°C

## VLB12100LFP-M-G2 — Compact

- Nominal voltage: 12.8V · Capacity: 100Ah
- Continuous discharge: 100A
- Compact case, same cells as the Standard line, no Bluetooth
- BMS fault indication: see the user manual (UM) — the reference sheet does not list alarm codes

## VLB12150-CIBUS-G1 — Pro, CI-Bus

- Nominal voltage: 12.8V · Capacity: 150Ah · Energy: 1920Wh
- Continuous discharge: 150A
- CI-Bus interface: reports state of charge, current and temperature to the vehicle panel
- Self-heating below 0°C
